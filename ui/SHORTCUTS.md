# Workspace shortcuts

| Action | Windows / Linux | macOS |
|---|---|---|
| Run the selected compiler stage | `Ctrl+Enter` | `⌘+Enter` |
| Find a file in the current project | `Ctrl+K` | `⌘+K` |
| Save the current project in this browser | `Ctrl+S` | `⌘+S` |
| Editor navigation and editing | Monaco Editor shortcuts | Monaco Editor shortcuts |

`Ctrl+S`/`⌘+S` confirms that the workspace is stored in this browser's local
storage. It does **not** create a Git commit or sync changes to GitHub.
For editor-specific key bindings, see the
[Monaco Editor keyboard shortcuts](https://github.com/microsoft/monaco-editor#keyboard-shortcuts)
documentation.
